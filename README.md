:# Coursera E-Learning Platform 🚀

An educational platform inspired by Coursera, designed to provide users with a seamless and interactive learning experience. Developed as a Web Programming project at Arab International University (AIU).

## 📝 Project Description
The platform allows users to register accounts, browse a wide variety of online courses, view the latest news and promotional offers, and access a Frequently Asked Questions (FAQ) section for guidance. It is intended to enhance digital learning accessibility, streamline course management, and provide a user-friendly interface for learners of all ages.

## ✨ Key Features
**User Authentication:** Secure login and registration system with data validation to ensure only authorized users can access the platform.
**Dynamic Home Page:** Displays news, offers, daily tips, and an image slider to engage users and highlight important updates.
**Course Management:** Comprehensive courses page where users can explore all available courses, including course descriptions, schedules, and instructors.
* **Admin Management Panel:** Full dashboard built for administrators to seamlessly add, modify, and manage courses and prices in real-time.
**FAQ Section:** Provides answers to common questions to assist users in navigating the platform efficiently.
**Responsive Design:** Fully responsive layout using HTML, CSS (Flexbox, Media Queries), and JavaScript, ensuring compatibility across different devices and screen size.

## 🛠️ Technologies Used
**Frontend:** HTML5, CSS3 (Flexbox & Media Queries), JavaScript (ES6).
**Backend:** PHP.
**Database:** MySQL.

## 🚀 How to Run the Project Locally
1. Clone this repository to your local machine.
2. Move the project folder into your local server directory (e.g., `C:/xampp/htdocs/`).
3. Open **XAMPP Control Panel** and start **Apache** and **MySQL**.
4. Go to `http://localhost/phpmyadmin/`, create a new database named `user_db`, and import the provided `user_db.sql` file.
5. Open your browser and navigate to `http://localhost/coursera_project/login.php`.
